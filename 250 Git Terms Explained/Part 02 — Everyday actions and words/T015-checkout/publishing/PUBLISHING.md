Git checkout: two different jobs

Checkout is one name covering two different jobs. Selecting a branch changes your development context; selecting a commit directly gives a detached HEAD. Restoring a selected file keeps the current branch in place. When the source is an earlier commit, the restored content also enters staging. Restoration can replace local edits, so check what would be lost.
