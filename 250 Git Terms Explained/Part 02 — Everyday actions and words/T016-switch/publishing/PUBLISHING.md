## Patreon
Title: Git switch: change your working context

An urgent bug can interrupt work on a feature. Git switch selects another development branch in the same project and updates the working files and staging area for that target. Your recorded feature commits remain on their branch. Switching creates no commit by itself.

Compatible uncommitted edits can follow you. If switching would lose local changes, Git normally stops, giving you a chance to resolve the situation.

Takeaway: Switch chooses the branch you are working on; compatible local edits may follow, while Git normally refuses a switch that would lose them.

Source: https://git-scm.com/docs/git-switch
