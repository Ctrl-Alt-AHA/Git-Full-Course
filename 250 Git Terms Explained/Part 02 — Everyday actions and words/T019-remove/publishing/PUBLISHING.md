## Patreon
Title: Removing a file: the folder, the index and history

Retiring an outdated help page involves two different places: your working folder and the index, which prepares the next commit. Ordinary folder deletion can leave the old index entry in place. Git’s removal command normally removes both the working copy and its index entry. The cached-only form removes the index entry while leaving the local file alone.

No commit happens automatically. Earlier commits retain the content they recorded; removing a file now does not erase its history.

Takeaway: prepare the absence, then commit.
