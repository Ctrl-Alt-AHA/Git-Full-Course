# Editable cover artwork

The two HTML files are separate compositions at their native output sizes: vertical1080×1920 and landscape1280×720. They load bundled Inter700 and JetBrainsMono400 WOFF2 files via relative paths. Open them through the project-local preview server, await fonts, and capture exactly the viewport size as a high-quality JPEG with no browser chrome.

These are external publishing artwork. They are not inserted as a flash into the video. Use the metadata's existing-frame timestamp when a platform's cover selector requires a video frame. Check actual upload crops and overlays before posting.
